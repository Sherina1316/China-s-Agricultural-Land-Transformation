# Suggested code availability response

We apologize for the inconvenience caused by the previously inaccessible GitHub
link. We have reorganised and expanded the analysis scripts and updated the
public repository to ensure that the code is accessible and reproducible. The
repository now contains a complete English-language workflow, including scripts
for CACD-derived cropland extent extraction, cropland extent--crop sown area
diagnostics, exact decomposition, principal component analysis with varimax
rotation, spatial autocorrelation testing, GWR/GTWR/TWR local regression, Monte
Carlo uncertainty diagnostics and figure generation. We also added a detailed
README file, input templates, validation utilities, a full-workflow runner and
method notes describing the interpretation of GWR, TWR and GTWR outputs.

Code repository:
https://github.com/Sherina1316/China-s-Agricultural-Land-Transformation

Please note that access to GitHub may depend on local network conditions or
institutional access policies in some regions.
