# Suggested response to the code-availability comment

**Reviewer comment:** It seems that the code is not available via the GitHub link.

**Response:** We apologize for the inconvenience caused by the inaccessible GitHub link. We have reorganised the analysis scripts and updated the public repository to ensure that the code is accessible and reproducible. The repository now contains a complete English-language workflow, including scripts for CACD-derived cropland extent extraction, cropland extent--crop sown area diagnostics, exact decomposition, principal component analysis with varimax rotation, spatial autocorrelation testing, GWR/GTWR/TWR local regression, Monte Carlo uncertainty diagnostics and figure generation. We also added a detailed README file describing the input data structure, software environment, execution order, and interpretation of GWR, TWR and GTWR outputs. The revised manuscript includes the updated Code Availability statement.
